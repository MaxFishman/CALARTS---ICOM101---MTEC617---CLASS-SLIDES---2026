<!-- 01 / the third language -->

HTML, CSS… and behavior.

HTML gives a page structure, CSS gives it style — and JavaScript gives it behavior: things that happen and change after the page loads.

Clicks, hovers, key presses, animations, live updates — that's all JavaScript. It's a real programming language, so today we start with its building blocks.

<!-- 02 / console.log — our window in -->

Print to the console.

script.js
console.log(5);
console.log('Hello World!');
Console
5
'Hello World!'

The console is a panel (in DevTools) that shows messages for developers. console.log(...) prints whatever's in the parentheses so you can see your work. End statements with a ;.

<!-- 03 / comments -->

Notes the computer ignores.

script.js
// a single-line comment
console.log(5); // …or after some code

/*
  a multi-line comment
  none of this runs
*/

Comments are for humans — they explain code to teammates and to future-you. // comments one line; /* … */ wraps many.

<!-- 05 / arithmetic operators -->

Math with numbers.

script.js
console.log(3 + 4);
console.log(9 / 3);
console.log(11 % 3);
Console
7
3
2 // remainder

Operators: + add, - subtract, * multiply, / divide, % remainder (modulo). 11 % 3 is 2 — 3 fits into 11 three times, leaving 2.

<!-- 06 / string concatenation -->

Gluing text together.

script.js
console.log('hi' + 'ya');
console.log('I love to ' + 'code.');
Console
'hiya'
'I love to code.'

The + operator on strings concatenates — joins them exactly. Watch your spaces: 'love to ' keeps the trailing space so words don't collide.

<!-- 07 / properties & methods · the dot -->

Ask data about itself.

script.js
// property — stored info
console.log('Hello'.length);

// method — an action
console.log('hello'.toUpperCase());
console.log('Hey'.startsWith('H'));
Console
5
'HELLO'
true

The . is the dot operator. A property holds info (.length); a method does something and needs () (.toUpperCase()). Sound familiar? console.log() is a method too.

<!-- 08 / built-in objects: Math -->

Tools that come with JS.

script.js
// random number, 0 to 1
Math.random();

// a whole number, 0–49
Math.floor(Math.random() * 50);
Console
0.4817…
24

Math is a built-in object full of methods. Math.random() gives 0–1; multiply by 50, then Math.floor() rounds down to a whole number.

<!-- 09 / variables — var, let, const -->

Containers for values.

script.js
let myName = 'Arya';
console.log(myName);   // Arya
letthe value can change later. The everyday choice.
constthe value is constant — reassigning throws an error.
varthe old, pre-2015 way. You'll see it, but prefer let/const.

Names use camelCase (myName), can't start with a number, and are case-sensitive. = is the assignment operator.

<!-- 10 / updating a variable -->

Change what's inside.

script.js
let w = 4;
w += 1;   // same as w = w + 1
console.log(w);  // 5

let a = 10;
a++;         // add 1  → 11
a--;         // take 1 → 10

Use let when a value needs to change. const can't be reassigned.

Shortcuts: +=, -=, *=, /= update in place. ++ and -- add or subtract 1. A let with no value starts as undefined.

<!-- 11 / template literals & typeof -->

Drop values into text.

script.js
const myPet = 'armadillo';
console.log(`I own a pet ${myPet}.`);

console.log(typeof myPet);
Console
'I own a pet armadillo.'
'string'

Wrap a string in backticks ` ` and insert values with ${ } — cleaner than gluing with +. typeof tells you a value's data type.

<!-- 12 / listening for events -->

Make the page react.

index.html + script.js
<!-- inline -->
<button onclick="alert('Hi!')">Click</button>

// or with a listener
const btn = document.getElementById('hi');
btn.addEventListener('click', () => {
  console.log('Hello World!');
});
click the button — it's live

An event is something that happens — a click, hover, or key press — that can trigger your code. Two ways: an inline attribute, or addEventListener in a script (the cleaner way).

<!-- 13 / jQuery — a helper library -->

Select like CSS, with $.

add jQuery in <head>, then:
$('p')          // all <p> elements
$('.my-class')  // class "my-class"
$('#my-id')     // id "my-id"
$('div.my-class p') // combined

$('#my-id').hide();  // then act on it
$("p")by tag — same as CSS p.
$(".class")by class — same as CSS .class.
$("#id")by id — same as CSS #id.

jQuery is a JavaScript library that simplifies working with the page. Its $() selectors mirror the CSS selectors you already know.

<!-- 14 / jQuery animations -->

Move & fade with one call.

script.js
$('button').click(function() {
  $(this).fadeOut('slow');
});

// also: fadeIn() slideUp()
//       slideDown() animate()
click to fade — live demo
fade me

jQuery bundles ready-made animations: fadeIn/Out, slideUp/Down, and animate() for custom motion — the smooth changes we did in CSS, now triggered by code.
