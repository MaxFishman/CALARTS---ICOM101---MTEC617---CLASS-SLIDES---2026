<!-- 01 / what is HTML? -->

The skeleton of
every web page.

HTML gives structure to the content on a website — images, text, video. It's usually the first language developers, designers, and marketers learn.

If this is your first time touching code: I'm excited for what you're about to create.

<!-- 02 / HyperText Markup Language -->

Say the name slowly.

Markup

A language that defines the structure & presentation of raw text.

Raw text

The computer interprets plain text wrapped in HTML elements.

HyperText

Text that links to other text — hyperlinks. You clicked a few to get here.

<!-- 03 / anatomy of an element -->

Every element has three parts.

<p>Hello World!</p>
↑
opening tag ↑
content ↑
closing tag
└──────── together, they make one element ────────┘

<!-- 04 / the body element -->

Only what's in the body
reaches the screen.

index.html
<body>
  <p>What's up, doc?</p>
</body>
output

What's up, doc?

Content lives between the opening <body> and closing </body> tags. Text, images, buttons — it all goes here.

<!-- 05 / structure = a family tree -->

Parents, children, nesting.

index.html
<body>
  <div>
    <h1>Why use divs?</h1>
    <p>A child of the div</p>
  </div>
</body>
body parent
  └─ div child of body
      ├─ h1 grandchild
      └─ p grandchild

A nested element is a child; the one around it is the parent. This whole set of relationships is hierarchy — and children can inherit styling from parents (more in CSS). Indent two spaces per level.

<!-- 06 / headings — six sizes -->

Six levels, largest to smallest.

h1Main heading
h2Subheading
h3Sub-subheading
h4Smaller still
h5Smaller again
h6Smallest heading
index.html
<h1>BREAKING NEWS</h1>

<h1> is for the main heading — use it once for the most important title. <h2>–<h6> are subheadings, ordered largest to smallest.

<!-- 07 / the div — a container -->

Divide the page into sections.

index.html
<body>
  <div>
    <h1>Why use divs?</h1>
    <p>Great for grouping!</p>
  </div>
</body>
output

Why use divs?

Great for grouping!

<div> is short for "division." It has no visual look of its own — but it groups elements so you can style them together later. Nest and indent two spaces.

<!-- 08 / attributes — name + value -->

Add info to a tag.

index.html
<div id="intro">
  <h1>Introduction</h1>
</div>
id="intro"
↑
name ↑
value

Attributes go in the opening tag. The id attribute labels a specific element — really useful when you reuse an element and need to tell copies apart.

<!-- 09 / paragraphs & spans -->

Blocks vs. inline text.

index.html
<p><span>Self-driving cars</span>
are anticipated to replace up to
2 million jobs.</p>
output

Self-driving cars are anticipated to replace up to 2 million jobs.

<p> holds a block of plain text. <span> wraps a short inline piece — same line as the surrounding text — so you can target it on its own.

<!-- 10 / em & strong -->

Emphasis, built in.

index.html
<p><strong>The Nile River</strong>
is the <em>longest</em> river
in the world.</p>
output

The Nile River is the longest river in the world, measuring over 6,850 km.

<strong> marks important text — browsers render it bold. <em> adds emphasis — usually shown italic.

<!-- 11 / the line break -->

One tag, no closing.

index.html
<p>The Nile is the longest<br>
river in the world,<br>
measuring over 6,850 km.</p>
output

The Nile is the longest
river in the world,
measuring over 6,850 km.

Whitespace in your code doesn't move things on screen. <br> forces a line break — and it's unusual: it has only an opening tag, no closing tag.

<!-- 12 / unordered lists -->

Bullets — no order needed.

index.html
<ul>
  <li>Limes</li>
  <li>Tortillas</li>
  <li>Chicken</li>
</ul>
output
  • Limes
  • Tortillas
  • Chicken

<ul> is the list; each item is an <li>. The <ul> shouldn't hold raw text directly — every item needs its own <li>.

<!-- 13 / ordered lists -->

Numbered — when order matters.

index.html
<ol>
  <li>Preheat oven to 350°.</li>
  <li>Mix flour & salt.</li>
  <li>Cream butter & sugar.</li>
</ol>
output
  1. Preheat oven to 350°.
  2. Mix flour & salt.
  3. Cream butter & sugar.

Same idea as <ul>, but <ol> numbers each item — perfect for steps in a process or a ranking.

<!-- 14 / tags that carry meaning -->

Article · Figure · Nav.

<article>

Independent, self-contained content that makes sense on its own and could be distributed elsewhere.

e.g. forum post · blog post · news story
<figure>

Self-contained media — illustrations, diagrams, photos, code listings. Remove it and the flow still reads.

pair with <figcaption> for a caption
<nav>

A block of major navigation links. Screen readers use it to find — or skip — your menus.

only for major nav, not every link

// discuss — these don't look special in the browser, but they tell people, search engines, and assistive tech what each part means.

<!-- 15 / links & the href attribute -->

The hyperlink returns.

index.html
<a href="https://w3schools.com">
  Visit W3Schools
</a>
output
Visit W3Schools

The <a> (anchor) tag makes a link. Its href attribute is the destination URL — no href, no hyperlink.

<!-- 16 / img, src & alt -->

Images are linked, not inserted.

index.html
<img
  src="img_girl.jpg"
  alt="Girl in a jacket"
  width="500" height="600">
output
alt: "Girl in a jacket"
(shown if the image can't load)

The <img> tag makes a holding space for an image it links to. Two required attributes: src (the path) and alt (text shown if it can't load — and read aloud by screen readers).
