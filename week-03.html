Introduction
to CSS

ICOM101 / MTEC617 Week 03 CalArts · Spring ’23

<!-- 01 / what is CSS? -->

HTML builds it.
CSS makes it beautiful.

HTML is the structure of every page — but on its own it's plain. Cascading Style Sheets is the language we use to style that structure.

Colors, fonts, sizes, images, spacing, positioning — if it's about how a page looks, CSS is the tool for the job.

<!-- 02 / the anatomy of a ruleset -->

One rule, five parts.

h1 {
  color: blue;
}
selectortargets the element to style — here, every <h1>.
declaration blockeverything inside the curly braces { }.
declarationone property: value pair — color: blue;
propertythe characteristic you're changing — color.
valuewhat you set it to — blue. End with a semicolon.

<!-- 03 / three places to write CSS -->

Inline · Internal · External.

1 · Inline
<p style="color:red;">Hi</p>

A style attribute right on the tag. Multiple styles? Separate with semicolons.

quick — but rarely used
2 · Internal
<style> p { color:red; } </style>

A <style> block inside <head>. Styles the whole page at once.

better — still not best
3 · External
/* style.css */
p { color:red; }

A separate .css file. HTML stays clean; CSS stays maintainable.

✓ best practice

<!-- 04 / linking an external stylesheet -->

Connect the two files.

index.html — inside <head>
<!-- from another folder / the web -->
<link href="styles/style.css"
      rel="stylesheet">

<!-- same folder: a relative path -->
<link href="./style.css" rel="stylesheet">
hrefthe path to the CSS file — a URL, or a relative path like ./style.css.
relthe relationship — for a stylesheet, always "stylesheet".

<link> lives in the <head> and is self-closing. Without it, the HTML can't find the CSS and no styles apply.

<!-- 05 / the box model -->

Every element lives in a box.

margin
padding
content
margin — space outside border — the frame padding — space inside content — the text or image

<!-- 06 / height & width -->

Sizing the content.

style.css
p {
  height: 80px;
  width: 240px;
}
output
240 × 80 px

px means pixels — an exact size, the same on every device. Great for precision, but a pixel-width box that fills a laptop will overflow a phone.

<!-- 07 / borders — a frame around the box -->

Width · style · color.

style.css
p {
  border: 3px solid coral;
}
output

A paragraph with a coral border.

Three values in one line: width (px, or thin/medium/thick), style (solid, dotted, none…), and color (one of 140 named colors, or a code). Anything you skip uses its default.

<!-- 08 / border-radius — round the corners -->

Corners don't have to be square.

style.css
.card {
  border: 3px solid blue;
  border-radius: 12px;
}
/* a perfect circle: */
.dot { border-radius: 50%; }
output

Equal width & height + border-radius: 50% makes a perfect circle.

<!-- 09 / padding — space inside -->

Room between content & border.

style.css
.box {
  border: 3px solid coral;
  padding: 16px;
}
/* one side only: */
padding-bottom: 16px;
output
no padding 16px padding

Padding is like the mat between a picture and its frame. Use padding-top / -right / -bottom / -left to target one side.

<!-- 10 / margin — space outside -->

Push other elements away.

style.css
p { margin: 20px; }

/* center a fixed-width box: */
.headline {
  width: 400px;
  margin: 0 auto;
}
output
margin: 0 auto → centered

margin: 0 auto centers a block horizontally — the 0 sets top/bottom, auto splits the leftover space evenly. It only works if the element has a set width.

<!-- 11 / a margin quirk -->

Vertical margins collapse.

↔ Horizontal — they add

Two side-by-side elements with 20px margins sit 40px apart. Left + right margins sum.

↕ Vertical — they collapse

Stacked elements with 10px and 30px margins sit 30px apart — the browser keeps the larger, not the sum.

// remember — padding never collapses. This surprises everyone the first time a gap is smaller than they expected.

<!-- 12 / overflow — when content spills -->

What happens to what won't fit?

style.css
.box { overflow: scroll; }
visiblespills outside the box (the default).
hiddenthe overflow is clipped and hidden.
scrolladds a scrollbar to reach the rest.
overflow: scroll
This box is short, but its content is long. Because overflow is set to scroll, a scrollbar appears so you can reach everything. Keep scrolling — there's more text down here than the box can show at once, so the browser hands you a scrollbar instead of hiding it or spilling it out.

<!-- 13 / start from a clean slate -->

Reset the browser's defaults.

style.css — the very first rule
* {
  margin: 0;
  padding: 0;
}

Every browser ships a hidden user-agent stylesheet — its own defaults for margin, padding, and more. ("User agent" is just a fancy word for the browser.)

The * is the universal selector — it targets every element. This is often the first rule in an external stylesheet, so you build on a clean slate.

<!-- 14 / font-family & font stacks -->

Choosing a typeface.

style.css
h1 {
  font-family: Georgia, 'Times New Roman', serif;
}
serif vs sans-serif

Serif — little feet on the letters

Sans-serif — clean, no feet

A font stack lists fallbacks: the browser tries each in order until one is available, ending with a generic keyword (serif / sans-serif). Wrap multi-word names in quotes: 'Times New Roman'.

<!-- 15 / weight, style & transform -->

Bold, italic, uppercase.

style.css
font-weight: 700;      /* or: bold */
font-style: italic;
text-transform: uppercase;
output

font-weight: 700

font-style: italic

text-transform: uppercase

font-weight takes keywords (normal, bold) or numbers 100–900 (400 = normal, 700 = bold). Not every font offers every weight.

<!-- 16 / spacing, line-height & alignment -->

Laying text out.

style.css
letter-spacing: 2px;
word-spacing: 0.3em;
line-height: 1.4;
text-align: center;
output

Letter-spacing widens the gaps.

A centered paragraph with generous line-height, so the lines breathe as they wrap.

Prefer a unitless line-height (like 1.4) — it scales with the font size automatically. Use em for spacing so it, too, tracks the type size.

<!-- 17 / web fonts — beyond the safe list -->

Borrow any font from the web.

index.html — inside <head>
<!-- 1. link the font (Google Fonts) -->
<link href="…fonts.googleapis.com/…Roboto"
      rel="stylesheet">

/* 2. then use it in your CSS */
h1 { font-family: 'Roboto', sans-serif; }

Web-safe fonts are reliable but limited. Web fonts — from free services like Google Fonts and Adobe Fonts — let you use almost any typeface.

Pick a font & its styles on the service, copy the generated <link> into your <head>, then name it in font-family. Extra-credit territory for the homework.
