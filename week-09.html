<!-- 01 / the goal -->

Build a real website.

Create a fully functional five-page website or app that showcases everything you've learned — HTML, CSS, JavaScript, and WordPress — with best-practice SEO & Analytics.

This simulates building a real-world site: rich media, a working contact form, clean code structure, accessibility, and analytics integration.

// meta note — this very slideshow uses almost every technique on the list. So can you.

<!-- 02 / page structure -->

At least five pages.

yoursite HomeAboutGalleryBlogContact
🏠Homelanding & intro
👤Aboutwho you are
🖼️Gallerymedia / images
📝Blogposts / projects
✉️Contactform + links

Five pages — separate or a one-page scroll. Every page needs a consistent navigation menu and a footer (copyright + privacy/terms links).

<!-- 03 / HTML content requirements -->

Structure & content.

🔤Typography & formatting
  • All six headings <h1>–<h6>
  • Paragraphs, <strong>, <em>, underline, <br>
  • Styled hyperlinks with hover & visited states
  • Ordered & unordered lists
🎬Embeds & external content
  • At least one iframe — YouTube, Google Map, Spotify, CodePen, p5.js…
  • A Google Font via <link> or @import
  • <figure> + <figcaption> for an image or media

<!-- 04 / CSS requirements -->

Style & layout.

🧱Structure
  • Internal and external stylesheets
  • Layout with Flexbox / Grid (or Bootstrap / Tailwind)
  • Media queries — mobile, tablet, desktop
✨Details
  • Custom nav bar (not default links)
  • Custom fonts & typography
  • Styled buttons with hover
  • Link states: hover, visited, active
  • ≥ 1 animation or transition
📦Must include
  • One form
  • One button
  • One card-style layout

<!-- 05 / functionality + JS -->

Sign your work in code.

script.js
console.log('Built by: Your Name');
console.log('GitHub: @yourusername');
console.log('Contact: you@email.com');

Use JavaScript in at least one place: console.log your name, GitHub username, and contact info…

…so nerds like me know it's you who coded the site. 😎 (Bonus points for doing more with JS, of course.)

<!-- 06 / SEO + accessibility -->

Findable & usable.

🔍SEO basics
  • <title>, <meta description>, <meta charset> on every page
  • Optimize & compress media for page speed
  • Sitemap / index page (optional)
♿Accessibility
  • Meaningful alt text on every image
  • Headings in proper order — no skipping levels
  • Semantic HTML throughout

<!-- 07 / Google Analytics -->

Measure the traffic.

Set up and embed a Google Analytics 4 tracking code — and make sure it appears on every page.

You'll submit a screenshot of your Analytics dashboard (or share access with Max) as proof it's working.

// why — analytics is how real sites learn who visits, what they read, and what to improve.

<!-- 08 / contact page -->

A working contact form.

✉️The form
  • Fields for name, email, and message
  • A styled submit button
  • No backend? Use Formspree, Netlify Forms, or W3Forms
🔗Alternate contact
  • An email link
  • Social links
  • Anything else people can reach you by

<!-- 09 / two ways to build it -->

Pick your path.

🔹Option A — Custom Code
  • Built with HTML, CSS & JavaScript
  • Host on GitHub Pages or Netlify
  • Include a readme.md about your project
🔹Option B — WordPress
  • Custom theme or a builder like Elementor
  • Custom CSS overrides
  • Plugins for SEO, forms, analytics, layout
  • Hosted at a URL we can visit

🌓 Dark / light mode toggle 🖼️ Slideshow or lightbox 🎨 CSS variables for theming 🚧 Custom 404 page ⭐ Custom favicon
