<!-- 01 / what is WordPress? -->

A content management system.

WordPress (a CMS) lets you create and manage a website through a visual dashboard — no writing HTML & CSS by hand for every page.

Under the hood it's built on PHP and a MySQL database. It powers everything from simple blogs to complex online stores — which is why it runs a huge share of the web.

<!-- 02 / how a page gets built -->

Assembled on every visit.

🌐Visitorrequests a page in their browser.
→
⚙️Server + PHPruns the WordPress code.
→
🗄️MySQLsupplies content & settings.
→
📄HTML / CSS / JSgenerated & sent back to display.

Unlike the static HTML files we've written, a WordPress page is built fresh from the database each time it's requested.

<!-- 04 / two ways to start -->

Online or on your machine.

☁️Online (hosted)
  1. Pick a host (Bluehost, SiteGround…) — many offer one-click installs.
  2. Choose a domain name.
  3. Follow prompts to install & set a username / password.
  4. Log in, pick a theme, add content.
💻Locally (your computer)
  1. Install a local server: XAMPP or MAMP.
  2. Download WordPress from wordpress.org.
  3. Create a database, then run the installer at localhost/…
  4. Log in and start building.

<!-- 05 / choosing a host -->

Where your site lives.

Shared

Many sites share one server. Cheapest, simplest.

best for: beginners, budgets
VPS

Your own slice of a server — more control & resources.

best for: growing traffic
Dedicated

A whole physical server to yourself. Priciest, most powerful.

best for: large, secure sites
Cloud

Scale resources up & down on demand.

best for: spiky traffic

Everything is managed from the dashboard — the admin area behind your site.

Log in by adding /wp-admin to your site's URL (e.g. www.example.com/wp-admin), then enter your username & password. The left menu is your map: Posts, Pages, Appearance, Plugins, Settings.

<!-- 08 / a key distinction -->

Posts vs. Pages.

📝 Posts

  • Time-based, organized by date.
  • Show up in your blog feed & archives.
  • Use categories & tags.
  • e.g. news, blog entries, updates.
vs

📄 Pages

  • Static content, not dated.
  • Not in the blog feed.
  • Use templates for layout.
  • e.g. About Us, Contact.

<!-- 11 / themes — design & layout -->

Change the whole look.

✅Using a theme
  1. Appearance ▸ Themes.
  2. Browse the library, Live Preview one you like.
  3. Activate to apply it to your site.
🛠Building a theme
  1. Needs some HTML, CSS & PHP.
  2. New folder in wp-content/themes.
  3. Add style.css (styles) & index.php (main template).
  4. Use PHP to include header/footer & template tags for dynamic content.

// the HTML & CSS you've learned is exactly what lives inside a theme.

<!-- 12 / menus — site navigation -->

Build the navigation.

  1. Appearance ▸ Menus opens the Menu Editor.
  2. Name it, click Create Menu.
  3. Add Items — Pages, Posts, or Custom Links.
  4. Drag & drop to reorder; nest items to make sub-menus.
  5. Assign it to a location (header, footer, sidebar) under Manage Locations.

Menus are how visitors navigate your site.

You can use different menus in different locations, and plugins can add extras like icons or mega-menus.

<!-- 14 / keeping it updated -->

Update for security.

  1. Back up first — always, before any update.
  2. Go to the Updates section of the dashboard.
  3. Update Now for core — don't close the tab while it runs.
  4. Then update your plugins & themes.
  5. For major versions, check release notes for compatibility.

Updates bring security patches, bug fixes, and new features.

Staying current is one of the best ways to protect your site from being exploited.

<!-- 15 / backing up -->

Your safety net.

A backup plugin like UpdraftPlus lets you save a full copy of your site — files and database — before you change anything.

If an update breaks something, you Restore and you're back to normal.

  1. Install & activate UpdraftPlus.
  2. Click Backup Now before updating.
  3. Store it off-site — Google Drive, Dropbox.
  4. Schedule automatic, regular backups.
  5. Broke something? Restore from a backup.
