## Overview

This week we learned that HTML builds it, and CSS makes it beautiful. CSS (Cascading Style Sheets) is the language we use to style HTML structure — colors, fonts, sizes, images, spacing, positioning. If it's about how a page looks, CSS is the tool.

For this homework you'll take a project you've built (or start a fresh one) and bring it to life with CSS. You'll write rulesets, use the box model to control spacing, change colors and fonts, and target elements with a class attribute.

## What you'll practice

- Writing CSS rulesets (selector, declaration block, declaration, property, value)
- Using the box model: padding, margin, and borders
- Changing an element's color and background-color
- Changing an element's font from the browser default
- Using a class attribute to style HTML selectively
- (Extra credit) Loading a web font from Google Fonts

## The assignment

**Style your project.** Fork last week's assignment, or start a fresh project. Then add CSS to style your HTML by completing each step below.

1. **Add CSS to style your HTML using the box model.** Use at least one of: `padding`, `margin`, or a `border` on an element. (For example: `p { border: 3px solid coral; }`, `.box { padding: 16px; }`, or `p { margin: 20px; }`.)
2. **Change an element's `color` or `background-color`.** Pick any element and set its text color or its background color to something other than the default.
3. **Change an element's font from the default.** Use `font-family` to give an element a new font stack — for example `h1 { font-family: Georgia, 'Times New Roman', serif; }`.
4. **Use at least one `class` attribute to style some HTML selectively.** Add a class to one or more elements and write a rule that targets that class (for example, a `.card` or `.headline` class).
5. **If you didn't do this last week, add an `<img>` and an `<a>` tag** to your project.
