## Overview

This week you learned that one page can adapt its layout to whatever screen it lands on — phones, tablets, laptops, and giant monitors. A layout that fills a laptop will overflow a phone, so we use **media queries** to adjust our styles as the screen gets smaller or larger. For this homework, you'll make your own project adapt, and you'll preview it across devices using Chrome DevTools.

## What you'll practice

- Writing a media query to change styles at a small screen width
- Shrinking text or stacking columns on small screens
- Previewing your page across devices with Chrome DevTools
- Finding and fixing anything that overflows or breaks on phone width
- (Optional) Exploring a CSS framework like Bootstrap

## The assignment

**Make your site adapt.** Work on the project you have been building.

1. **Add a media query to your project.** Use it to shrink text or stack columns on small screens.
2. **Open Chrome DevTools** (Cmd+Shift+M to toggle the device toolbar) and **preview your project across devices.**
3. **Fix anything that overflows or breaks on phone width.**
4. **Curious? (Optional)** Explore a CSS framework like Bootstrap.

Closing reminder: keep testing on real screens.

## Submission

Submit your updated project so your media query and mobile-friendly layout can be reviewed. Make sure the changes above are in place and that your page has been previewed across devices in Chrome DevTools.
