## Overview

This week we moved from writing HTML and CSS by hand to using a content management system (CMS). WordPress lets you create and manage a whole website through a visual dashboard, with the HTML and CSS you already know living inside the theme. For this homework you'll set up your own WordPress site and take it through the everyday tasks a site owner does: pick a theme, add content, build navigation, add a plugin, and make a backup.

The title of the assignment is **"Try WordPress."** Content first, code underneath.

## What you'll practice

- Setting up a WordPress site, either locally or on a free host
- Installing and activating a theme to control the look and feel
- Telling Posts and Pages apart, and creating one of each
- Building a menu so visitors can navigate your site
- Installing a plugin to add functionality
- Making a backup of your site

## The assignment

Complete each item below. These come straight from the Week 06 homework checklist — nothing extra is required.

1. **Set up a WordPress site** — locally (using MAMP or XAMPP) or on a free host.
2. **Install and activate a theme you like.** Browse to a theme, preview it, and activate it so it controls your site's layout and design.
3. **Create one Page — an About page.** Pages are for static content that isn't dated.
4. **Create one Post — a blog entry.** Posts are time-based and show up in your blog feed.
5. **Build a menu and add your pages to it.** Menus are how visitors navigate your site.
6. **Install one plugin** to add some functionality.
7. **Make a backup** of your site.

## Submission

Turn in a short write-up (a document or a set of screenshots) that shows:

- Your site with its activated theme
- The About **Page** you created
- The blog **Post** you created
- The menu you built, with your pages added to it
- The plugin you installed
- Confirmation that you made a backup

Note whether you set your site up **locally** or on a **free host**.
