This folder holds the **teaching plans, homework assignments, and student worksheets** for every week of *Intro to Web Development*. Every document is built **entirely from the course's own lecture slides** (the `week-01.html` … `week-09.html` decks in the repository root) — no outside material has been added.

Each week's folder contains three files:

| File | For whom | What it is |
|------|----------|------------|
| `teacher-guide.md` | Instructor | A weekly lesson plan: objectives, key terms, a slide-by-slide flow, discussion prompts, and common pitfalls to watch for. |
| `assignment.md` | Students | That week's homework — the task, a checklist, what to submit, and how it's graded. |
| `student-worksheet.md` | Students | An in-class / study worksheet of exercises drawn from the week's slides, with an answer key. |

## How the homework builds

The assignments are **cumulative** — students carry one project forward across the term:

- **Week 1** — analyze three sites like a designer (no code yet).
- **Week 2** — hand-write a first HTML page using the elements taught.
- **Week 3** — style that page with CSS (box model, color, fonts).
- **Week 4** — make it responsive with a media query.
- **Week 5** — add positioning, color/background, and a hover transition.
- **Week 6** — spin up a WordPress site (theme, a page, a post, a menu, a plugin, a backup).
- **Week 7** — add JavaScript (a script, a variable, a template literal, a click event).
- **Week 8** — plug in a public API and explore a framework.
- **Week 9 (Capstone)** — combine everything into a real, live, five-page site, graded out of 100.
