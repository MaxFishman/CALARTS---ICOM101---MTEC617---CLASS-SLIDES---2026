## Answer key

**Key terms**

1. **API (Application Programming Interface):** a set of rules and tools that let two software applications communicate — the interface between programs. One app can share data and functionality with another without either knowing how the other is built inside.
2. **Request:** your app asks for something through the API (for example, it needs a map on the page).
3. **Response:** the service sends the result back (for example, Google Maps sends map data back). You use the result without ever seeing the other system's code.

**The request/response flow** (correct order):

1. Your app (needs something, like a map on the page)
2. Request
3. The API (the agreed-upon doorway)
4. The service (sends the data back)
5. Response back

**Short answer**

1. Three types of APIs:
   - **Web APIs** — let different web applications talk over the internet (e.g. Google Maps API).
   - **Operating System APIs** — give programs access to OS functions: files, network, hardware (e.g. file system access).
   - **Library-Based APIs** — expose the functions and resources of a specific software library (e.g. a charting library).
2. Two everyday APIs (examples): **maps** (a website drops in the Google Maps API to show an interactive map) and **payments** (a social platform uses a payment API so you can buy something inside the app). Other examples: logins with Google, weather widgets, embedded videos, "share to…" buttons.
3. Why APIs matter: **reuse code** (plug in functionality that already exists instead of building from scratch), **combine powers** (integrate several APIs into one program for more advanced applications), **collaborate and innovate** (mixing services creates products that wouldn't have been possible alone), and **better experience** (users reach info and features from other apps without leaving yours).
4. A **framework** gives you a set of pre-built software components — a foundation for building web applications. Instead of wiring up everything yourself, you start from proven structure and build quickly on top of it.
