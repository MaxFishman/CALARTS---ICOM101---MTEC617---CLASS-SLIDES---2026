# Final Project — Build a Real Website

> **Intro to Web Development · ICOM101 / MTEC617 · CalArts · Spring 2026**
> **Week 09 — Final Project (Capstone)**
> _Assignment_

## The goal

Build a real website. Create a fully functional five-page website or app that showcases everything you've learned — HTML, CSS, JavaScript, and WordPress — with best-practice SEO & Analytics.

This simulates building a real-world site: rich media, a working contact form, clean code structure, accessibility, and analytics integration. This very slideshow uses almost every technique on the list. So can you.

## Page structure

At least five pages. Sitemap: **Home, About, Gallery, Blog, Contact.**

- **Home** = landing & intro
- **About** = who you are
- **Gallery** = media/images
- **Blog** = posts/projects
- **Contact** = form + links

Five pages — separate pages **OR** a one-page scroll.

Every page needs a consistent navigation menu and a footer (copyright + privacy/terms links).

## HTML content requirements

**Typography & formatting:**

- All six headings `<h1>`–`<h6>`
- Paragraphs, `<strong>`, `<em>`, underline, `<br>`
- Styled hyperlinks with hover & visited states
- Ordered & unordered lists

**Embeds & external content:**

- At least one iframe — YouTube, Google Map, Spotify, CodePen, p5.js…
- A Google Font via `<link>` or `@import`
- `<figure>` + `<figcaption>` for an image or media

## CSS requirements

**Structure:**

- Internal AND external stylesheets
- Layout with Flexbox/Grid (or Bootstrap/Tailwind)
- Media queries — mobile, tablet, desktop

**Details:**

- Custom nav bar (not default links)
- Custom fonts & typography
- Styled buttons with hover
- Link states hover/visited/active
- ≥1 animation or transition

**Must include:** one form, one button, one card-style layout.

## JavaScript requirement

Sign your work in code. Use JavaScript in at least one place: `console.log` your name, GitHub username, and contact info — so nerds like me know it's you who coded the site. (Bonus points for doing more with JS.)

```javascript
console.log('Built by: Your Name');
console.log('GitHub: @yourusername');
console.log('Contact: you@email.com');
```

## SEO & accessibility

**SEO basics:**

- `<title>`, `<meta description>`, `<meta charset>` on every page
- Optimize & compress media for page speed
- Sitemap/index page (optional)

**Accessibility:**

- Meaningful alt text on every image
- Headings in proper order — no skipping levels
- Semantic HTML throughout

## Google Analytics

Set up and embed a Google Analytics 4 tracking code — and make sure it appears on every page.

Submit a screenshot of your Analytics dashboard (or share access with Max) as proof it's working.

Analytics is how real sites learn who visits, what they read, and what to improve.

## Contact page

A working contact form:

- Fields for name, email, and message
- A styled submit button
- No backend? Use Formspree, Netlify Forms, or W3Forms

**Alternate contact:** an email link, social links, anything else people can reach you by.

## Two ways to build it

**Option A — Custom Code:**

- Built with HTML, CSS & JavaScript
- Host on GitHub Pages or Netlify
- Include a `readme.md` about your project

**Option B — WordPress:**

- Custom theme or a builder like Elementor
- Custom CSS overrides
- Plugins for SEO, forms, analytics, layout
- Hosted at a URL we can visit
