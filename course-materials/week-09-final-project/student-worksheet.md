## Requirements self-check

**HTML — typography & formatting**

- [ ] All six headings `<h1>`–`<h6>`
- [ ] Paragraphs, `<strong>`, `<em>`, underline, `<br>`
- [ ] Styled hyperlinks with hover & visited states
- [ ] Ordered & unordered lists

**HTML — embeds & external content**

- [ ] At least one iframe (YouTube, Google Map, Spotify, CodePen, p5.js…)
- [ ] A Google Font via `<link>` or `@import`
- [ ] `<figure>` + `<figcaption>` for an image or media

**CSS — structure**

- [ ] Internal AND external stylesheets
- [ ] Layout with Flexbox/Grid (or Bootstrap/Tailwind)
- [ ] Media queries — mobile, tablet, desktop

**CSS — details**

- [ ] Custom nav bar (not default links)
- [ ] Custom fonts & typography
- [ ] Styled buttons with hover
- [ ] Link states hover/visited/active
- [ ] ≥1 animation or transition
- [ ] One form
- [ ] One button
- [ ] One card-style layout

**JavaScript**

- [ ] `console.log` your name, GitHub username, and contact info

```javascript
console.log('Built by: Your Name');
console.log('GitHub: @yourusername');
console.log('Contact: you@email.com');
```

**SEO & accessibility**

- [ ] `<title>`, `<meta description>`, `<meta charset>` on every page
- [ ] Optimize & compress media for page speed
- [ ] Sitemap/index page (optional)
- [ ] Meaningful alt text on every image
- [ ] Headings in proper order — no skipping levels
- [ ] Semantic HTML throughout

**Google Analytics**

- [ ] GA4 tracking code set up
- [ ] Tracking appears on every page
- [ ] Screenshot of dashboard ready (or share access with Max)

**Contact form**

- [ ] Fields for name, email, and message
- [ ] A styled submit button
- [ ] No backend? Formspree, Netlify Forms, or W3Forms
- [ ] Alternate contact — email link, social links, anything else
