# Week 09 Teacher Guide — Final Project

> **Intro to Web Development · ICOM101 / MTEC617 · CalArts · Spring 2026**
> **Week 09 — Final Project (Capstone)**
> _Teacher Guide_

## At a glance

This is the capstone. Over 15 slides, students are asked to build a fully functional five-page website (or one-page scroll) that pulls together every technique from the course — HTML, CSS, JavaScript, and WordPress — plus best-practice SEO and Google Analytics.

- **Due: April 30 / May 7.**
- This week ties together all prior weeks: HTML fundamentals, CSS and responsive design, typography, JavaScript, WordPress, and the SEO/accessibility/analytics content. Nothing new is introduced — this is where they prove they can integrate it all into a real, live site.

## Learning objectives

By the end of the final project, students will be able to:

- Plan and build a complete five-page website (or one-page scroll) with consistent navigation and footer.
- Apply the full HTML toolkit — headings, formatting, lists, links, embeds/iframes, figures.
- Style a responsive site with internal and external CSS, Flexbox/Grid, media queries, animations, and reusable components (form, button, card).
- Use JavaScript to sign their work in the console and, ideally, do more.
- Implement SEO basics and accessibility (semantic HTML, alt text, heading order).
- Set up and embed Google Analytics 4 across every page.
- Build a working contact form using a no-backend service.
- Deploy a live site (GitHub Pages, Netlify, or hosted WordPress) and present it.

## How to present this deck

**Slide 1 — Cover ("Final Project").** Set the stakes: this is the capstone. Announce the due dates up front: April 30 / May 7.

**Slide 2 — The Goal.** Frame it as building a real-world site: rich media, a working contact form, clean code structure, accessibility, and analytics. Emphasize the meta note — this very slideshow uses almost every technique on the list, so they have a working example in front of them.

**Slide 3 — Page Structure.** Walk the sitemap: Home, About, Gallery, Blog, Contact. Clarify they may do five separate pages OR a one-page scroll. Stress the consistent nav menu and footer on every page.

**Slide 4 — HTML Requirements.** Go through typography/formatting (all six headings, paragraphs, strong/em/underline/br, styled links, both list types) and embeds (≥1 iframe, a Google Font, figure + figcaption).

**Slide 5 — CSS Requirements.** Cover structure (internal AND external stylesheets, Flexbox/Grid, media queries for mobile/tablet/desktop) and details (custom nav, custom fonts, styled buttons, link states, ≥1 animation/transition). Remind them of the three must-haves: one form, one button, one card.

**Slide 6 — JavaScript.** Show the exact console.log signature. Make clear the minimum bar is signing their work; bonus points for doing more with JS.

**Slide 7 — SEO & Accessibility.** SEO basics (title, meta description, charset on every page; compress media; optional sitemap) and accessibility (alt text, heading order, semantic HTML).

**Slide 8 — Google Analytics.** GA4 tracking on every page; proof via screenshot or shared access with Max. Emphasize the "why" — analytics is how real sites learn who visits, what they read, and what to improve.

**Slide 9 — Contact Page.** Working form (name, email, message), styled submit button, no-backend options (Formspree, Netlify Forms, W3Forms), plus alternate contact methods.

**Slide 10 — Tech Stack.** Present Option A (custom code, GitHub Pages/Netlify, readme.md) vs Option B (WordPress theme/Elementor, custom CSS, plugins, live URL). Let students self-select.

**Slide 11 — Bonus.** Walk the five bonus items (up to +10). Point out the psst note — this slideshow itself does the dark/light theme, a slideshow, CSS variables, and a favicon; invite them to peek at the source.

**Slide 12 — Grading Rubric.** Put the full 100-point rubric on screen and read it criterion by criterion so grading is transparent.

**Slide 13 — Submission Checklist.** The four deliverables: live URL, project folder, reflection, analytics screenshot.

**Slide 14 — Final Presentation.** Set expectations for the 5–7 minute live walkthrough.

**Slide 15 — Wrap-Up.** Recap everything the course covered and repeat the due dates: April 30 / May 7.

## Grading & submission logistics

Confirm each student turns in all four items:

- **Live URL** (GitHub Pages, Netlify, or hosted WordPress site)
- **Full project folder** (your code files or WordPress export)
- **Short reflection** (2–3 paragraphs) — what you built · what you're most proud of · what was hard & how you solved it
- **Analytics screenshot** — showing your dashboard, or share access with Max

For the analytics proof specifically: accept either a screenshot of the GA4 dashboard OR shared dashboard access with Max as verification that tracking is live on every page.

## Presentation day

Each student delivers a **5–7 minute** presentation:

- A live walkthrough of their site
- Their inspiration & concept
- The HTML, CSS & JS features they used — media, responsive design, SEO & analytics
- A quick test on phone & another browser
- One feature they're especially proud of
- One challenge and how they solved it, plus future improvements

Remind students to have their live site open and their code ready to reference before they present.
