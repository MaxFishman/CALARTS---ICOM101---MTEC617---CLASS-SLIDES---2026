<!-- 01 / what are we building? -->

Directories, not
destinations.

We build sites that act as a hub for content — but don't always host the content themselves.

For now we're less interested in fully-featured, rich-media browsing portfolios, and more concerned with creating useful directories that link to content around the web.

<!-- 02 / key terms -->

The vocabulary.

server →
The computer that hosts your website. Servers make the internet work — in this class we'll avoid dealing with them directly wherever possible.
client →
The computer visiting your website (the opposite of the server). All the code we write runs on the client.
front / back end →
Client side / server side, respectively. e.g. "HTML is a front-end language."

the front door.

<!-- 07 / scripting vs markup -->

Two kinds of language.

Scripting →

  • Gives instructions to control another program — doesn't work standalone.
  • Interpreted, not compiled — scanned line by line.
  • No compiler involved.
  • e.g. JavaScript, PHP, Perl, Python, VBScript.

Markup →

  • Prepares the structure and look of a page — presentational.
  • No logic, no algorithms, asks the computer nothing.
  • Tells the browser how to structure & style data.
  • e.g. HTML, CSS, XML.

All scripting languages are programming languages — but not all programming languages are scripting languages.

<!-- 08 / what happens when you visit a website -->

Like calling a phone number.

Every site has a unique IP address — like a phone number. DNS is the address book that maps names to addresses.

1
You type an address into the browser and hit enter.
2
Your ISP asks a DNS (Domain Name Server) where that site lives.
3
The DNS resolves the request — it looks up the domain and returns the site's IP address to your ISP, which forwards your request there.
4
The server receives your request and is expected to generate a response.→ next slide: what that response can be.

<!-- 09 / the server generates a response -->

Three ways to answer.

<dynamic>

A Twitter server

Dynamically generates your custom homepage and returns it.

<json>

An API endpoint

Calculates some data and returns it in a machine-readable format.

<html>

A static site

Just returns a pre-written chunk of HTML.
